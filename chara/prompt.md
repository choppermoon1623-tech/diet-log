## 作るもの

ダイエット記録アプリ（iPhone向けの単一HTML）で、ユーザーを応援してくれるマスコット少女キャラクター「カロン」を、**インラインSVGの手描きベクター**として作ります。画像ファイルは使いません。SVGの図形とパスをあなた自身で組み立ててください。

## chara.js の形

先頭にコメント1行、あとは次の1つのオブジェクトだけ。`export` も `module.exports` も付けないでください（`<script>` でそのまま読み込む単一HTMLに貼り込みます）。

    /* 応援キャラ「カロン」— 表情5種のインラインSVG */
    const CHARA = {
      smile:  '<svg viewBox="0 0 200 240" xmlns="http://www.w3.org/2000/svg">...</svg>',
      cheer:  '<svg ...>...</svg>',
      joy:    '<svg ...>...</svg>',
      gentle: '<svg ...>...</svg>',
      worry:  '<svg ...>...</svg>'
    };

文字列はシングルクォートで囲んでください。SVG内の属性値はダブルクォートを使ってください。バッククォートとドル記号は使わないでください。

## 表情5種

| キー | 場面 | 姿 |
|---|---|---|
| smile | ふつう・まだ記録がない | にこにこ。片手を顔の横に上げて軽く振っている |
| cheer | もう少しで目標 | 「ファイト！」両手のこぶしを胸の前で握って応援。目は元気に見開く |
| joy | 目標達成・体重が減った | 大喜び。両手を上げてバンザイ。目は上に弧を描いた笑顔（^ ^）。ほおに赤み |
| gentle | 食べすぎた日 | やさしい微笑み。責めない顔。片手を胸にあてて「だいじょうぶ」 |
| worry | 減らしすぎ・がんばりすぎ | 少し心配そうな眉（ハの字）。口は小さく「へ」の字ぎみ。両手を前に出して止める仕草 |

## 絵の作り方（ここが一番大事）

- **頭・髪・顔の輪郭・胴・服のパスは5種すべてで完全に同じ座標を使う**こと。差し替えるのは「目・眉・口・ほおの赤み・腕と手」だけ。同じ子に見えることを最優先してください。
- 画風はフラットなアニメ調。グラデーションや影は使わず、**べた塗り＋均一な太さの輪郭線**で。輪郭線は stroke="#4a3b35"、stroke-width="3"、stroke-linecap="round"、stroke-linejoin="round"。
- 上半身のみ（腰から上）。viewBox="0 0 200 240"。背景は透明にし、背景用の矩形は置かないこと。
- 配色：
  - 髪 #6b4f3f（内側の濃い部分 #5a4133）
  - 肌 #ffe0cd
  - 白いシャツ #ffffff
  - その上に着る若草色のエプロン #7fc7a4
  - リボンなどのさし色 #e8836b
  - ほおの赤み #f4a08c
  - 瞳 #3f6b57、白目 #ffffff、瞳の上に白いハイライトの小円
- 顔の中心は x=100。目の高さは y=95 あたり。頭のてっぺんは y=20 あたり、あごは y=130 あたり、肩は y=175 あたりを目安に。**この基準を5種で必ずそろえる**こと。
- 目は大きめのアニメ目にしてください。丸より少し縦長の楕円が扱いやすいです。
- 髪型はショートボブに、横で結んだ小さなサイドテールを1つ。前髪はぱっつん気味。
- **健康的で清潔感のある、中学校の教室に貼っても差しつかえない絵柄にしてください。** 肌の露出は顔と手だけ。体の線を強調しない。服はきちんと着ているものにする。
- svgタグには width と height を書かず、viewBox と xmlns だけ付けてください（大きさはCSS側で決めます）。
- SVG内に style要素 や class属性 は使わず、すべて属性で直接指定してください。
- 描画順は「後ろの髪 → 体と服 → 腕 → 首と顔 → 前髪 → 顔のパーツ」の順にすると重なりが自然になります。
