# カロリー帳（ダイエット記録アプリ）

食事と消費カロリーの記録に特化した、iPhone 向けの単一 HTML アプリ。
`index.html` 1ファイルだけで動く。外部ライブラリなし・通信なし。

## できること

| タブ | 中身 |
|---|---|
| 📝 きょう | 日付を送りながら、朝昼夕＋間食の食事と運動を記録。収支（摂取−消費）が大きく出る |
| 📈 きろく | 直近7日の平均収支、収支の棒グラフ（14日）、体重の折れ線（60日）、日ごとの一覧 |
| ⭐ 定番 | よく食べる物・よくする運動を登録。「きょう」から1タップで入る |
| ⚙️ 設定 | 身長・年齢・活動量・目標、Dropbox へのバックアップ、計算の説明 |

- 食品データ **149件**（主食／めん・丼／外食／肉魚卵／野菜汁物／飲みもの／おやつ／調味料）、量は ×0.5〜×2 で調整可
- 運動データ **35件**（METs 付き）、時間は 10〜60分から選択
- どちらも見つからなければ手入力でき、そのまま定番に登録できる

## 写真からカロリーを入れる

API キーもサーバも使わず、**Claude アプリに聞いて答えを貼り戻す**流れにしてある。追加コストはゼロ。

食事の追加シート →「📷 写真」タブ：

1. **質問文をコピー**（`PHOTO_PROMPT`）。器の大きさから量を推定させ、調理油やドレッシングも足させ、幅ではなく代表値を出させ、最後に `品名|カロリー` の行だけを並べさせる指示になっている
2. **Claude を開く**（`https://claude.ai/new`）。カメラで食事を撮って、その文を貼って送る
3. **返事をまるごと貼る** → `parseMealText()` が品名とカロリーを拾う

読み取った品はチェックを外したり数字を直したりしてから、まとめてその食事に入る。`合計` の行は品目にせず、Claude の言う合計として脇に出して突き合わせに使う。

`parseMealText()` は返事の形のぶれに強くしてある。前置きの文章、`**太字**`、箇条書き（`-` `・` `1.`）、縦棒（`|` `｜`）・コロン（`:` `：`）・`…` 区切り、`約400kcal` のような書き方、区切り線、いずれも通る。地の文は落ちる（カロリー表記で終わらない行、30字を超える品名、0以下や5000超の数値は捨てる）。

なぜ API を使わないか：このアプリは静的 HTML でサーバがないので、API を使うならキーをブラウザに置くか中継を立てるかになる。個人利用ならどちらも可能だが、貼り戻し方式ならキーの管理もコストも発生しない。API 方式に切り替えたくなったら、`readAnswer()` の前段に fetch を挟むだけで済む形にしてある。

## カロリーの計算

**消費 ＝ 基礎代謝 ＋ 生活の活動 ＋ 運動**

- 基礎代謝：ミフリン・セントジョー式（体重・身長・年齢・性別）
- 生活の活動：基礎代謝 ×（活動係数 − 1）。活動係数は 1.20 / 1.30 / 1.45 / 1.60 から選ぶ
- 運動：`(METs − 1) × 1.05 × 体重kg × 時間h`
  - **1METs を引いている**のがポイント。安静時の消費はすでに基礎代謝で数えているので、引かないと二重計上になる。そのぶん他のアプリより少し小さい数字が出る

体重は日ごとに記録でき、その日の記録がなければ直近の過去の値を使う。

## データの置き場所

この端末の `localStorage`（キー `dietLog_v1`）だけ。サーバには一切送らない。

Dropbox へは **手動バックアップ**でやりとりする：

- 設定 →「📤 書き出す」→ iPhone の共有メニュー →「"ファイル"に保存」→ Dropbox
- 設定 →「📥 読みこむ」→ Dropbox の `dietlog_YYYYMMDD.json` を選ぶ
  - 読みこみ方は2通り：**まるごと置きかえ** / **記録のない日だけ足す**（機種変更や複数端末の合流用）

## iPhone での使い方

Safari で開いて、共有ボタン →「ホーム画面に追加」。
全画面のアプリのように立ち上がる（`apple-mobile-web-app-capable`）。
セーフエリア対応・ダークモード対応・タップ時のズーム抑止済み。

## 作りのメモ

- 単一ファイル。`<script>` 内に食品/運動データ・状態・描画がすべて入っている
- 描画は「状態を変えて `render()` を呼ぶ」だけの素朴な作り。仮想DOMなし
- グラフは inline SVG を文字列で組み立てている（`balChart` / `weightChart`）
- 色は先頭の `:root` 変数に集約。`prefers-color-scheme: dark` で入れ替え
- 写真タブの3ステップは `.step` の縦線つきレイアウト。質問文は `PHOTO_PROMPT` 定数1本
- クリップボードは `navigator.clipboard.writeText()`。使えないとき（`file://` など）は質問文の textarea を選択状態にするフォールバックに落ちる
- `onclick="f('名前')"` に食品名を埋めているので、`jsq()` で **JS文字列 → HTML属性** の二重エスケープをかけている（`esc()` だけだと `'` を含む名前で壊れる）
- 中身が空の日は `save()` のたびに捨てる（日付を送っただけで空データがたまらないように）

## 注意

食品のカロリーは日本食品標準成分表などをもとにした**1人前のおおよその目安**。
数字そのものより、続けた日数と体重の線を見るためのもの。
